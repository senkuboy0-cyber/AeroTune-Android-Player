# AeroTune - Cyberpunk Music Player

Ultra-premium Android music player featuring:

- Cyberpunk Dark Theme with Neon accents
- Glassmorphism UI components
- Splash Screen with animations
- Full Player and Mini Player
- Material 3 Design

## Build

```bash
./gradlew assembleDebug
```

## Tech Stack
- Kotlin 2.1
- Jetpack Compose
- Material 3
- Media3 (ExoPlayer)
- Hilt DI
- Coil Image Loading

## Color Palette
- Background: #060910 (Deep Dark)
- Primary Accent: #00E5FF (Neon Cyan)
- Secondary Accent: #FF1744 (Neon Pink)
- Text: #FFFFFF / #9E9E9E

## Features
- Animated Splash Screen
- Modern Glassmorphism Cards
- Full Screen Player with animations
- Mini Player Bar
- Library with track list
