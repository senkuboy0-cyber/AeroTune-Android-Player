# AeroTune - Cyberpunk Music Player

Ultra-premium Android music player with Cyberpunk UI theme.

## Build
```bash
./gradlew assembleDebug
```

## Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- Media3 (ExoPlayer)
- Hilt DI
- Coil Image Loading

## Features
- Cyberpunk Dark Theme
- Glassmorphism UI
- Local audio playback
- Modern animations
