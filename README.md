# AeroTune - Ultra-Premium Android Music Player

AeroTune is a modern Android music player featuring:

- Ultra-Premium Dark Mode UI with Glassmorphism effects
- Local audio file scanning and playback
- Play/Pause/Skip controls
- Shuffle and Repeat modes
- Beautiful Now Playing screen with album art

## Build

```bash
./gradlew assembleRelease
```

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Media3 (ExoPlayer)
- Hilt for Dependency Injection
- Coil for image loading
- MVVM Architecture
